# SS_Enhance 게임 기획과 플레이 방법

이 문서는 현재 플레이 경험, 조작법, 장면 흐름과 게임 규칙의 설계 기준을 정의한다.

## 게임 목표

핵심 경험은 `강화 준비 → 실시간 제련 → 강화 판정 → 검의 진화 → 전투와 성장`이다.
플레이어는 단순 확률 버튼이 아니라 온도와 리듬을 직접 조절해 강화 결과에 개입한다.
화려한 콘솔 연출과 함께 입력 결과를 즉시 이해할 수 있는 시각적 피드백을 제공한다.

현재는 첫 번째 플레이 가능한 수직 슬라이스로, 강화 준비부터 결과 확인까지 구현돼 있다.
전투와 장기 성장 시스템은 이후 확장 범위다.

## 현재 게임 흐름

```text
Title
  └─ Enter/Space
       ↓
Settings
  ├─ 언어 선택
  ├─ 난이도 선택
  └─ Enter/Space
       ↓
Forge
  └─ 강화 비용 지불
       ↓
Forging
  └─ 3회 타격 또는 제한 시간 종료
       ↓
Result
  └─ Enter/Space
       ↓
Forge
```

## 플레이 방법

### 타이틀

- 기본 표시 언어는 한국어다.
- `Enter` 또는 `Space`: 설정 화면으로 이동
- `Esc`: 게임 종료

### 설정

- 기본 설정은 `한국어 / 보통`이다.
- `↑`, `↓`, `W`, `S`: 언어와 난이도 항목 이동
- `←`, `→`, `A`, `D`: 선택한 항목의 값 변경
- `Enter` 또는 `Space`: 설정을 적용하고 게임 시작
- `Esc`: 타이틀로 돌아가기
- 언어는 화면 문구와 검 이름에만 영향을 준다.
- 난이도는 강화 비용과 자연 냉각 속도에 영향을 주며 기본 성공 확률을 직접 변경하지 않는다.

| 난이도 | 강화 비용 | 자연 냉각 | 제한 시간 | 의도 |
| --- | ---: | ---: | ---: | --- |
| 쉬움 | 기본의 90% | 기본의 85% | 14초 | 온도를 여유 있게 유지하며 조작을 익힌다. |
| 보통 | 기본의 100% | 기본의 100% | 12초 | 원래 설계된 기준 밸런스를 사용한다. |
| 어려움 | 기본의 115% | 기본의 125% | 10초 | 빠른 냉각과 짧은 시간으로 온도·타격 관리를 어렵게 한다. |

### 대장간

- 현재 검의 강화 단계, 등급명, 기본 공명률과 강화 비용을 확인한다.
- `Enter` 또는 `Space`: 비용을 지불하고 강화 의식 시작
- `Q` 또는 `Esc`: 게임 종료
- 골드가 부족하면 플레이가 영구 중단되지 않도록 긴급 계약으로 600 G를 지급한다.

### 실시간 제련

- `A` 또는 `←`: 검의 열기를 낮춘다.
- `D` 또는 `→`: 화력을 높인다.
- `Space` 또는 `Enter`: 망치로 검을 타격한다.
- `Esc`: 현재 제련을 중단하고 대장간으로 돌아간다.
- 공명 온도 범위를 유지하면서 리듬 표시가 성공 구간에 들어왔을 때 타격하는 것이 목표다.
- 세 번 타격하거나 제한 시간이 끝나면 강화 결과를 판정한다.

### 결과

- 성공 여부, 이전·현재 강화 단계, 제련도와 최종 공명률을 표시한다.
- 결과 진입 직후 연속 입력을 막기 위해 최소 0.65초 동안 복귀 입력을 받지 않는다.
- 이후 `Enter`, `Space` 또는 `Esc`로 대장간에 돌아간다.

## 현재 강화 규칙

- 타격 점수는 타이밍 정확도 68%, 온도 정확도 32%를 합산한다.
- 타격 점수와 최종 성공 확률은 항상 `0.0f~1.0f` 범위를 보장한다.
- 세 번의 타격 평균이 최종 강화 확률에 영향을 준다.
- 완벽한 제련은 일정 확률로 두 단계 상승을 발생시킨다.
- 낮은 강화 단계에서 실패하면 단계를 유지한다.
- 높은 강화 단계에서는 기억 조각을 먼저 소모한다.
- 기억 조각이 없는 높은 단계에서 실패하면 강화 단계가 하나 내려간다.
- 검의 강화 단계, 골드와 기억 조각은 음수가 될 수 없다.
- 강화 판정은 연출보다 먼저 확정하며 파티클이나 프레임 속도가 결과를 바꾸지 않는다.

## 게임 규칙 구현 기준

- 강화 비용, 기본 확률과 실패 패널티는 `ForgeRules` 한 곳에서 관리한다.
- 난이도별 비용 배율은 `ForgeRules`, 자연 냉각 배율과 제한 시간은 `ForgeSession`에서 적용한다.
- UI는 확률이나 비용을 다시 계산하지 않고 Domain이 제공한 값을 표시한다.
- 타격 과정의 온도, 리듬, 제한 시간과 점수는 `ForgeSession`이 관리한다.
- 강화 판정에 필요한 난수 값은 외부에서 전달해 결과를 재현할 수 있게 한다.
- 모든 실시간 갱신에는 `deltaSeconds`를 사용해 프레임 속도와 무관한 동작을 보장한다.
- 밸런스 수치를 변경하면 이 문서와 관련 코드 주석을 함께 갱신한다.

## UI와 현지화 기준

- 한국어와 영어는 동일한 게임 정보를 전달해야 한다.
- 문구는 직역보다 콘솔 UI 영역에 맞는 자연스럽고 짧은 표현을 우선한다.
- 한글·CJK 전각 문자는 실제 표시 폭인 두 칸으로 배치하고 정렬한다.
- 게임 의미가 있는 수치와 판정은 렌더링 코드에서 새로 계산하지 않는다.
- 검의 현지화된 이름은 화면 표현이며 `Sword` 도메인 객체는 강화 단계와 등급만 관리한다.
